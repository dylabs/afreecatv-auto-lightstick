# SOOP 자동 응원봉 UI 개선 설계

## 요약

재생/정지 버튼을 토글로 통합하고, 설정 모달을 추가하여 타이머(자동 정지)와 랜덤 개수 기능을 제공한다.

## 버튼 바 변경

### Before
`📝 기록` `▶️ 시작` `⏹️ 정지` `[2초▼]` — 4개 요소

### After
`📝 기록` `▶️/⏹️ 토글` `⚙️ 설정` `[2초▼]` — 4개 요소

- **📝 기록**: 기존과 동일. `#write_area`에서 텍스트 캡처.
- **▶️/⏹️ 토글**: 하나의 버튼. 클릭 시 재생↔정지 전환. 재생 중이면 `⏹️` + active 스타일, 정지 상태면 `▶️`.
- **⚙️ 설정**: 클릭 시 설정 모달 열림.
- **[시간 선택]**: 기존과 동일하게 바에 유지. 0.8/1/1.5/2/3/5/10초.

## 설정 모달

중앙 모달 팝업. 배경 딤 처리. SOOP 다크 테마에 맞춘 디자인.

### 1. 자동 정지 타이머

- **토글 스위치**: ON/OFF
- **입력**: 숫자 + 단위(분/초) 선택
- **동작**: ON 상태에서 재생 시작 시, 설정된 시간 후 자동으로 `stopCheering()` 호출
- **OFF**: 수동 정지만 가능 (기존 동작)
- **기본값**: OFF, 5분

### 2. 랜덤 개수

- **토글 스위치**: ON/OFF
- **이모지 패턴 입력**: 반복할 단위 텍스트 (기본값: `/야광봉/`)
- **최소/최대 개수 입력**: 매 전송마다 min~max 사이 랜덤 정수로 패턴 반복
- **미리보기**: 현재 설정 기준 랜덤 결과 예시 표시
- **동작**: ON이면 매 interval마다 `패턴 x 랜덤개수`로 텍스트 생성하여 전송. OFF면 📝 기록 텍스트 그대로 전송.
- **기본값**: OFF, `/야광봉/`, 2~5개

### 저장

- **저장 버튼** 클릭 시 모든 설정을 localStorage에 저장하고 모달 닫기
- 페이지 새로고침 후에도 설정 유지
- localStorage 키: `cheerTimerEnabled`, `cheerTimerValue`, `cheerTimerUnit`, `cheerRandomEnabled`, `cheerRandomPattern`, `cheerRandomMin`, `cheerRandomMax`

## 기존 기능과의 관계

- **랜덤 OFF**: 📝 기록 텍스트 그대로 전송 (기존 동작과 동일)
- **랜덤 ON**: 📝 기록 텍스트 무시, 패턴 x 랜덤개수로 전송
- **타이머**: 재생 시작과 동시에 `setTimeout` 세팅, 정지 시 타이머도 클리어
- **하단 텍스트 표시**: 랜덤 ON이면 `현재: /야광봉/ x 2~5개 (랜덤)` 형태로 표시

## 파일 변경

| 파일 | 변경 내용 |
|---|---|
| `content.js` | 토글 버튼, 설정 모달, 타이머, 랜덤 로직 추가 |
| `styles.css` | 모달 스타일, 토글 스위치, 딤 배경 추가 |
| `manifest.json` | 변경 없음 (이미 수정 완료) |

## 기술 결정

- **모달 렌더링**: content.js에서 DOM 직접 생성 (프레임워크 없음, 기존 패턴 유지)
- **상태 관리**: 전역 변수 + localStorage (기존 패턴 유지)
- **타이머**: `setTimeout` 사용, 재생 중지 시 `clearTimeout`
- **랜덤**: `Math.floor(Math.random() * (max - min + 1)) + min`
